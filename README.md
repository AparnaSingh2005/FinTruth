
# FinTruth

### AI-Powered Financial Claim Verification Platform

FinTruth is an explainable, reliability-aware AI platform
that verifies financial claims using financial statements,
market indicators and financial news.

## Key Features

- Financial claim extraction
- Cross-source verification
- Financial metric calculations
- Contradiction detection
- Reliability-aware predictions
- Explainable AI

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- NLP and Transformers
- SHAP
- Streamlit
- FastAPI

## Research Objective

To investigate how AI can verify financial claims
under incomplete, noisy and conflicting evidence.

## Disclaimer

Initial datasets may contain synthetic records.
Synthetic records must not be interpreted as actual
financial information.
